Offline tools

Small tools that run in your browser

Each tool is a single HTML file that works with no internet connection. Nothing is uploaded; your data stays on your machine.

  • BPM.tap

    BPM tapper

    Tap, click or press a key along to a song to find its tempo: average and recent BPM, consistency, half/double time, a per-tap chart and a beat counter.

    Open →
  • GZIP.tool

    Gzip helper

    Compress text or files to gzip, zlib or raw deflate, and decompress them from a file, Base64 or hex, with header details (file name, date, OS), checksum checks and multi-member support.

    Open →
  • JSON.diff

    JSON diff

    Compare two JSON documents (or any text) structurally: changes by path, shared properties, JSON Patch, combinable field filters and saved comparisons.

    Open →
  • JSON.format

    JSON formatter

    Format, minify and validate JSON with exact error locations, repair common mistakes (comments, trailing commas, single quotes), browse it as a collapsible tree and query it by path.

    Open →

Made by LXST.digital. Everything runs in your browser; nothing is uploaded. To use a tool offline, save its page from your browser's File menu.
