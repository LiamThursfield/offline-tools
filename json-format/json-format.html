Paste, drop or open a file to format, validate and explore it. Common mistakes such as comments and trailing commas are fixed for you. Everything runs in your browser; nothing is uploaded.

Output

Syntax

Picks parts of the document. Everything else in the output (copy, download, tree) then works on the result.

$.address.citya nested property (the $ is optional)
items[0], items[-1]first and last element
items[*].idid of every element
$.*every top-level value
..idid at any depth
$["a key"]a key with spaces or special characters

A path without wildcards gives that value. With * or .. you get an array of every match.
